# VoiceBridge 0.13.0 · 认得朋友，安心开黑

- 首次验证邮箱并设置密码、昵称和头像；以后使用邮箱与密码登录，默认记住登录 30 天。支持找回密码、修改密码和个人资料跨设备同步。
- 全新「同频桥」图标，软件、托盘和网站标签页保持一致。深色标题栏去除白边，开关统一为白色开启、黑色关闭，并标明状态。
- 软件内直接打开屏幕共享与观看面板；双击画面放大，右下角全屏，保留浏览器备用入口。画面面板的开关不影响原生连麦。
- 网页连接、加解密与音频编解码移到独立 Worker，减少界面操作影响；刷新和短暂断线保留 90 秒恢复机会，恢复时尊重关麦和音量选择。
- 可设置关闭窗口时收起托盘或直接退出。音乐、人声降噪、成员独立音量、按键说话和房间大厅继续保留。
- 安装包减少无关语言资源；优先差分更新，支持断点续传和完整包回退。在房间内只提示或预约更新，不中断连麦安装。

旧客户端请更新后登录账号。原私密邀请可在登录后使用。现有服务器最多 4 个房间、每房间 8 人；有人时不限时，全员离开 30 分钟释放。服务器维护重启后需重新建房。

1080p／最高 60 帧受设备及网络影响。网页被系统完全冻结时不能保证持续采集；恢复后自动重连。更新清单签名和 HTTPS 不等于 Windows 商业代码签名，浏览器仍可能要求保留安装文件。
