## 安装与更新

- 当前 Windows 11 电脑从 0.12 升级到 0.13，设置文件的 SHA256 保持一致。已安装程序自检、10.0.14 自包含运行时及许可文件通过。未开启真实麦克风。
- 实际 0.12→0.13 差分下载 820089 字节，恢复后的 302 个包条目与完整包逐项一致。模拟差分失败后，正确回退到 73710818 字节的完整包。更新清单使用既有固定公钥验证。
- 全新 Windows 安装由正式发行工作流单独验证，失败时停止发布；结果随发行提供 `install-smoke.json`。
- 安装器 81242850 字节（约 77.5 MiB），较旧安装器 85974445 字节减少约 5.5%。差分约 801 KiB，较完整更新包减少约 98.9%。
- 同一网络分别下载旧／新安装器前 4 MiB：HTTP 206，约 3.96／3.97 秒，约 1.01 MiB/s。单位字节速度基本相同，仍受现有带宽与共享预算限制；主要改善是较小安装器及差分更新。

## 限制

自动化使用可丢弃账号、合成音频和画面，不采集真实麦克风或桌面。真人对端听感、真实游戏高负载、Windows 10 实机和跨设备延迟未测。合成设备中断不等同于实际 USB 耳机拔插。1080p／最高 60 帧是设备和网络允许时的目标。

界面阻塞 8 秒时仍收到音频数据并保留身份，但测量窗口最大发送间隔达 1219ms；这证明线程已分离，不代表每帧均匀。浏览器被系统完全冻结时，仍无法保证持续采集，恢复后会重新连接并提示恢复声音。

安装器未配置 Windows 商业代码签名。HTTPS、SHA256 与更新清单签名不能保证消除浏览器或 SmartScreen 提示。房间仍为内存会话，服务器维护重启后需要重新建房。
