# 0.13.0 验证记录

## 已完成的本机验证

- 网页／服务端 54 项测试通过，包括请求超时后恢复、一次性原生成员控制票据、账号验证、密码重设与撤销、头像规范化、SQLite 新 Worker 读取持久资料、强制登录、恢复身份及独立 Worker 的应用心跳／音频状态。
- Windows 27 项测试通过，包括 DPAPI 保存与恢复、损坏凭据不阻止启动、离线立即退出、延迟刷新不能恢复已退出账号、异常响应不导致启动崩溃、关闭行为偏好、更新验签／下载恢复及房间内延迟安装。
- 合成账号的实际 Windows 窗口和内嵌 WebView2 已检查双击放大、右下角全屏与 Esc 恢复、关闭画面页后保持关麦和原生会话；窗口内合成画面曾达到 1920×1080／54–56 帧。
- 100%、125%、150%、200% 离屏布局检查已完成；不等同于每种实体显示器和真实 DPI 环境。

实际 HTTPS 注册已建立账号并载入个人资料，SMTP 身份验证通过。两位观看者通过杭州 UDP 中继的 10 项视频操作检查通过。长时间测试、最终安装包与差分、正式部署结果在发布时追加。现有 6876 秒旧长测是被运行环境中断的检查点，没有最终通过结果，不能当作完整两小时测试。

## 验证边界

本机自动化使用专用可丢弃账号、合成音频和画面，不采集真实麦克风或桌面。真人听感、游戏高负载下的实际声卡行为、跨设备延迟和多运营商网络效果需要真人实测；合成测试不能证明绝无掉线或所有网络都达到 1080p60。
