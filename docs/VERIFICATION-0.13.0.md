## 验证边界

本机自动化使用专用可丢弃账号、合成音频和画面，不采集真实麦克风或桌面。真人听感、游戏高负载下的实际声卡行为、跨设备延迟和多运营商网络效果需要真人实测；合成测试不能证明绝无掉线或所有网络都达到 1080p60。

实测：8 人满员房间刷新后自动恢复同一成员身份，保留关麦、按键说话、40% 总收听音量和一位成员的人声静音；刷新没有重新请求合成麦克风。浏览器阻止自动播放时，恢复按钮可以启用收听而不重新开麦。

界面阻塞 8 秒的合成测试中，独立线程仍传出数据并保持成员身份；测量窗口收到 712 帧，记录的最大发送间隔为 1219ms。这证明界面与传输已分离，不代表每帧均匀或游戏中的真实声卡表现。
