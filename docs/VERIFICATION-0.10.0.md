# 0.10.0 发布验证（2026-10-28）

公共入口：`https://voicebridge-room.cn/`，杭州阿里云 ECS；网站显示渝ICP备2026026961号-1并链接工信部查询页。

| 范围 | 实际结果 |
| --- | --- |
| Node 自动测试 | 28 项通过：音频兼容、权限、限流、昵称、屏幕控制与邀请校验等 |
| .NET Windows 测试 | 14 项通过，锁定依赖还原和 win-x64 单文件发布成功 |
| 服务器暂存版本 | 首页备案展示、健康检查、免配置建房、WebSocket 入房、二进制逐字节转发、关房通过 |
| 本机至公网服务 | HTTP 跳转 HTTPS、有效证书、WSS、免密建房、三位测试成员加入、音频包转发和屏幕信令通过 |
| UDP 强制中继 | 10 项真实 Edge WebRTC 验证通过，两位观看者均使用 relay 候选并解码出合成视频 |
| TCP 强制中继 | 同样 10 项通过，明确限定 TCP 3478 路径 |
| TLS 强制中继 | 同样 10 项通过，明确限定 TURNS/TCP 5349 路径并使用有效域名证书 |

每组视频验证覆盖两人观看、来源像素、暂停占位、恢复、来源切换、实际发送码率参数、结束释放、换人共享和断线释放。合成视频在同一台测试电脑内生成与观看，但强制通过远端杭州中继传输；这不等同于两个家庭网络中的真实设备验收。

未采集真实屏幕、麦克风或私人内容。未声称已完成人工多显示器、所有 Windows/显卡/游戏组合、朋友端音质试听及 500 ms 端到端画面延迟测量。500 ms 是目标；网络、采集和编码可能使实际延迟更高。

TURN 使用十分钟会话凭据，总视频发送预算 5 Mbps；服务器另对中继端口的实际合计出口应用约 5 Mbps 限速。连接配额与流量上限独立，避免按连接提前预留全部带宽。该限制不覆盖音频/网站下载，公网流量仍按云服务商规则计费。
