# 0.11.0 验证记录

本文件在最终发布前补齐全部结果。合成验证不采集真实屏幕、麦克风或播放器，不代表两台独立电脑的真人验收。

已完成：35 项 Node 测试、17 项 .NET 测试；原生 RNNoise DLL 的噪声衰减和帧边界检查；单文件 EXE 的合成 Opus 与原生降噪加载；三小时房间生命周期模拟、房主离开、30 分钟空房回收、满员恢复、重放保护、过期凭据拒绝、限量队列、原身份重连及关闭客户端不散房。

真实 Edge 已完成两位合成画面观看者的选择、暂停／恢复、切换来源、发送器限额、结束释放及下一人共享验证。网页控制连接中断后恢复了同一成员、昵称、120% 麦克风增益及按键说话设置；重新加载网页后恢复保存的昵称。

布局使用生产 HTML/CSS 在隔离预览容器中验证，375、768、1024、1440 CSS px 及桌面 200% 布局倍率未发现横向溢出。共享预览宽度不超过 360 CSS px。Edge 当前连接的 viewport override 没有实际改变已有页面尺寸，因此未把该接口的空操作当作响应式验收。

20 分钟 UDP 远端 TURN 合成视频、人声及立体声音乐验证正在进行；TCP、TLS 与最终公网部署检查将在发布前记录。

已知边界：设备和网络决定实际帧率；本次远端中继长测在单台测试电脑运行多个端点，不能证明独立电脑的实际音质或端到端延迟。字幕／文字清晰度、真实麦克风听感及两台独立电脑的延迟仍需实际体验。
