# 场景配置与接收端校准

选择场景只是载入 VoiceBridge 的本机音频参数。它不表示 QQ、微信或游戏内部的降噪、语音门限或编码已经关闭，也不表示接收声音与本地完全一致。

## 每个场景分别保存什么

支持通用、QQ 语音、微信通话、无畏契约、和平精英模拟器五个场景。每个场景独立保存真实麦克风、虚拟发送设备、音乐播放器、两路音量、音乐声道和 20 / 40 / 60 ms 输出缓冲。

首次创建场景时沿用现有音量和来源作为中性起点，保留立体声及 20 ms 缓冲。这里没有凭空声称适用于某软件的“最佳参数”。切换前先全部停止；选择场景不会自动开始传送声音。调整完成后点“保存场景”，切换或正常退出时也会保存。

配置写入 `%LOCALAPPDATA%\VoiceBridge\settings.json`，覆盖前保存 `settings.json.previous`。这些文件可能包含私人设备标识，不应提交到公开仓库。

## 先确认平台真的收到了虚拟输入

在实际使用的通话中选择 `CABLE Output`，播放输出仍选耳机。普通默认输入和默认通信输入可能指向不同设备，各软件也可能保存自己的输入选择。

若软件跟随 Windows 默认输入，可展开“音频参数、输出检查与试听记录”，手动点击“将虚拟麦克风设为默认输入”。这会先备份，再更改 Windows 的普通、媒体、通信三种默认输入，影响所有跟随默认输入的软件；不会更改播放设备或软件内部的音频处理。

使用虚拟默认输入时，通话需要保持 VoiceBridge 运行并开启人声。退出程序不会自动恢复 Windows 默认输入。需要恢复时点击“恢复此前默认输入”；恢复只处理仍指向本次虚拟目标的角色，不覆盖之后被其他操作改过的输入。备份为本机 `default-input-before.json`。当前通话可能缓存设备选择，需要重新选择或重新进入通话。

## 参数的作用与限制

| 参数 | 实际作用 | 不能据此认定 |
|---|---|---|
| 两路音量 | 调整固定混音电平，分别保存 | 平台降噪已关闭 |
| 保留立体声 | 保持两路音乐声道 | 平台会用立体声编码 |
| 左右平均 | 将音乐两声道平均后送入两路输出 | 反相音乐不会抵消 |
| 仅左 / 仅右 | 用其中一路音乐复制到两路，便于排查相位抵消 | 仍保留原来的立体声空间效果 |
| 输出缓冲 | 调整 WASAPI 渲染缓冲，可能改善本机调度问题 | 关闭过滤、恢复压缩细节或端到端延迟达标 |

声道方式只作用于音乐，真实麦克风不随它改变。默认音乐仍使用固定增益和原有余量，不按讲话活动自动压低。

## 录制与试听本地虚拟输出

1. 先按需要开启人声和音乐，再展开检查区域。
2. 点击“录制虚拟输出 10 秒”，选择 WAV 保存位置。它读取 CABLE Output，包含当前已开启的人声和音乐，不会额外打开真实麦克风。
3. 再次点击可取消并保留已经收到的部分；正常退出也会取消检查。
4. 先暂停音乐播放器，再点击“试听本地录音”，避免两段音乐同时播放。程序用正常默认播放设备播放，不经过虚拟线缆，也不调用可能被设为音源的外部音乐播放器。用耳机试听。
5. 同名 `.wav.json` 保存本地电平、近静音窗口和采集统计。近静音也可能是歌曲安静段，不能直接判断为平台过滤。文件只保存在所选本机位置。

本地录音在平台处理之前，不能替代对方实际接收到的声音。当前录音属于选定场景和参数；改变参数后重新录制再对比。

## 各场景如何校准

- **QQ**：分别确认正在使用的私聊 / 群语音输入。若当前版本提供降噪、自动增益或音乐选项，逐项对比；不能假定不同入口使用相同设置。
- **微信**：用实际通话验证，不能用浏览器录音代替。若版本没有公开原声或降噪开关，本工具不能替它关闭处理。
- **无畏契约**：确认游戏输入，比较持续按住语音键时的只放音乐 / 同时讲话；按键说话控制发送时机，并不等于关闭降噪。游戏运行时同时查看本机捕获统计。
- **和平精英模拟器**：先核对模拟器 Windows 侧输入，再核对游戏内语音。若任一层提供麦克风增强或降噪选项，分层对比；模拟器还有音频转接环节。

请让对方听同一段音乐，分别确认安静段、鼓点 / 伴奏、只放音乐和同时讲话是否连续。只有得到实际反馈后才点“记录：对方试听正常”。该按钮只是保存用户反馈的时间和本机参数签名，不进行自动远端检测。参数改变后记录失效；更换平台版本、网络或接收设备也应重新测试。

捕获统计仅覆盖本机，启动 / 暂停、进程重启和调度都可能影响计数。本地输出正常而接收端仍过滤时，继续检查平台自身的处理、编码和传输；如没有可用的关闭入口，需要平台提供音乐 / 系统音频通道，无法靠一个预设保证原音一致。

## 技术依据

- [Windows 音频信号处理模式](https://learn.microsoft.com/zh-cn/windows-hardware/drivers/audio/audio-signal-processing-modes)：应用可请求 RAW 模式，并仍可自行进行处理；外部混音器不能据此替消费端取消内部处理。
- [腾讯 GME 音质选择](https://intl.cloud.tencent.com/zh/document/product/607/18522)：音质和降噪行为由 SDK 接入方配置；这不表明任一具体游戏公开了外部控制接口。
