# 一起听，一起聊：VoiceBridge 房间

v0.8.1 支持自己的音乐语音房间。朋友在浏览器进入同一房间即可互相讲话、收听伴奏，不必依赖 QQ、微信或游戏传输人声。伴奏的操作参考常见语音房间：选择音乐来源、固定音量、一键开关。

## 主持人

1. 退出托盘旧版，运行新版 Windows 11 x64 单文件 EXE。当前电脑的 HTTPS 发送配置沿用旧版，不在 EXE 中分发。
2. 打开 QQ音乐、网易云音乐或酷狗音乐，保持耳机正常听音，在“伴奏来源”选择对应播放器。
3. 点击“创建音乐房间”，等首段加密上传确认后点击“邀请朋友”，发送完整链接。
4. 自己点击“进入语音房间”。主持人页面默认音乐 0%，因为本机播放器已经有声音，避免两遍音乐重叠。人声音量仍可独立调节。
5. 在房间页面点击“进入房间（麦克风关闭）”，再主动开启麦克风并允许浏览器权限。主持人也通过该页面讲话；桌面下方的虚拟麦克风人声开关不控制房间麦克风。

## 朋友

用新版桌面 Edge / Chrome 打开完整邀请，填昵称，点击“进入房间（麦克风关闭）”。可以先只听音乐和别人讲话；需要讲话时点击“开启麦克风”。音乐伴奏和朋友人声有不同音量滑块。请戴耳机。

房间页提供真实麦克风列表及刷新按钮。首次允许权限后才能显示完整设备名称；若默认选中了 CABLE Output、Voicemeeter 或立体声混音，程序会停止该输入，请选择真实麦克风后重新开启。切换设备先关闭当前采集，不会自动开麦。

## 控制与退出

- 桌面“伴奏：开/关”只控制房间音乐，不中断人声。伴奏滑块只衰减传送的音乐，不改变你的本地听音，也不随讲话自动压低。
- 房间运行时 Ctrl+Alt+F9 控制伴奏，Ctrl+Alt+↑/↓ 改变房间伴奏音量。Ctrl+Alt+F8 仍只控制兼容虚拟麦克风。房间麦克风在页面上控制。
- “离开房间”释放浏览器麦克风并断开该成员。关闭麦克风后仍可收听。连接断开时会关闭麦克风，不会重连后自动开麦。
- 桌面“关闭房间”、全部停止、托盘退出会停止音乐并撤销房间，断开成员。若发送端断网未能撤销，房间在最后上传后最迟 120 秒过期。接收者可能先听完已缓冲的音乐。
- 最小化或点 × 只是收起到托盘，房间会继续。启动/开机自启不会自动开房或开麦。
- 一次选择一个音乐来源；切换前关闭房间后重新创建，新链接会更换密钥。

## 音质与限制

音乐继续使用 48 kHz 双声道未压缩 float32 PCM，不经过人声回声消除、降噪或自动增益。网页人声使用麦克风专属的回声消除/降噪，关闭自动增益，转换为 16 kHz 单声道 PCM16，通过 WSS 低缓冲独立传送。多人声音相加会做固定余量及峰值保护，不压低音乐。两个通道分别由浏览器播放。

音乐默认 2.4 秒接收缓冲，可选 1.2/4.8 秒；人声目标抖动缓冲约 160 ms，另有设备、网络和处理延迟。不承诺低于 100 ms、零杂音或零卡顿。主持人本机与朋友音乐**不是精确同步**；这是高质量音频传输，不是共享播放进度或卡拉 OK 对唱系统。

房间最多 8 人，免费中继有流量、休眠、性能和稳定性限制。每位收听者的音乐约 1.38 GB/小时，另加语音及协议流量。首次唤醒可能等待约一分钟。公共 EXE 不含发送密钥，其他主持人需按 [relay 部署文档](../relay/README.md)配置自己的服务。

## 保密范围

音乐与人声都在接收端解密。人声使用每位成员独立标识和 HKDF-SHA256 派生的 AES-256-GCM 密钥域，20 ms 一帧，认证数据绑定房间、成员与序号；中继只转发密文，不落盘录音。成员昵称、麦克风开关、连接元数据对中继可见，昵称和开关对房间内其他人可见。

完整链接同时授予收听和加入语音权限，持有者可参与房间；当前没有账号、踢人或管理员审核。只发给指定朋友，泄露时关闭重开。端到端加密仍依赖主持人与网页代码可信；恶意替换网页的托管者可以窃取页面里的密钥。
