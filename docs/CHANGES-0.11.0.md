# VoiceBridge 0.11.0

房间以语音交流和音乐共享为主，屏幕共享作为可展开的小卡片保留。

- 活跃房间不设使用时限；房主退出不散房。全员离开 30 分钟后回收；未入房的空创建请求仍会短期清理。服务器维护重启后需重新建房。
- 网络异常时保留成员身份 90 秒，自动重连；不会把房间邀请当作本机控制或恢复权限。重连中可关麦、调音量或退出；不恢复按键说话的按下状态。
- 昵称保存到当前 Windows 用户 AppData；浏览器独立使用时保存在本站本地存储。移动 EXE 不丢失设置，清理浏览器数据会清除网页昵称。
- 新增麦克风降噪开关，默认开启并记住选择。客户端使用 RNNoise 0.2，网页请求浏览器原生降噪。降噪仅作用于麦克风，不改变独立音乐通道，不增加自动增益或自动压低音乐。
- 默认清晰优先，目标 1920×1080、最高 60 帧；均衡目标 1080p30，流畅目标 720p30。网络或设备不足时优先降低帧率；界面显示实际发送／接收参数，档位不是实际画质保证。
- 更新 TURN 凭据时不再销毁视频连接；使用 ICE restart 续期。直连和中继采用不同预算，公网中继保留现有限速和开销余量。
- 保留每人音乐共享、任意程序音源、独立音量、按键说话、进出提示音、窗口／桌面选择、暂停、全屏和切换来源。

公共服务继续最多同时 4 个房间、每个房间最多 8 人；不增加服务器资源或流量套餐。10 Mbps 公网峰值、现有中继限速及观看人数会影响实际视频画质。
