# HTTPS 跨网音乐

v0.7.0 增加只使用 HTTPS 出站连接的加密音乐中继。它不需要临时反向隧道，不修改防火墙、代理或游戏，也不对外开放你的本机服务。朋友继续使用 QQ / 微信 / 游戏语音，同时打开音乐收听链接。

## 使用

1. 配好你自己的中继发送凭据后，界面会显示“使用本机已配置的 HTTPS 音乐中继”。
2. 选择音乐播放器，点击“开始独立分享”。默认关闭下方语音频道的音乐，避免重复；原来的人声通话继续。
3. 程序确认首段加密音乐上传成功后，提供复制按钮。朋友打开完整链接并点击“开始收听”，不需要账户或麦克风权限。
4. 接收页默认 2.4 秒缓冲，可选 1.2 秒 / 2.4 秒 / 4.8 秒。声音不经过原语音平台的滤波，但有更高的传输延迟。
5. 点击“停止独立分享”停止上传并发送撤销请求。若撤销时断网，房间在最后上传后 120 秒过期，接收端可能先播完已缓冲的一小段。

音乐只来自选中的播放器进程树，不采集真实麦克风。声音以未压缩 PCM 加密传输；解密密钥只在本机和完整邀请链接中。发送凭据由 Windows 当前用户 DPAPI 保护，不含在公共 EXE / 源码包中。

人声输入有两种选法：目标语音软件直接选真实麦克风，或仍选 CABLE Output 并单独开启 VoiceBridge 下方的“人声”。独立音乐链接不会替你自动开启人声；若目标软件选了虚拟麦克风而下方人声关闭，对方就听不到你的讲话。

本机试听仍是本地 WebSocket 链路，不能用来证明公网中继可用。需要检查上传确认、接收页解密接收数据以及另一网络的实际试听。不能承诺所有网络、所有设备都听到完全相同声音。

## 部署与免费限制

可移植中继完整代码、测试、环境变量和 Render Free 配置见 [relay/README.md](../relay/README.md)。需要 Node.js 22+，无需数据库和额外 npm 包。

免费服务会有带宽、休眠和稳定性限制。部署免费服务仍需服务提供商账户，注册条款应由用户本人确认；本软件不会购买资源或添加付款方式。使用公开 Git 仓库时，不必授予全部私有仓库权限。

本次已部署 Render Free 中继，公网健康检查、合成音上传与下载解密通过。用户本机发送配置单独保存在 Windows 用户目录，不含在公共下载中；其他分享者需部署并配置自己的服务。曾尝试的 Sites 服务在本机网络遭前置防护 HTTP 403 拒绝，不能将那次部署状态当作可用结果。

Render 服务使用手动部署，避免上传新的桌面源码时自动重启正在使用的中继。用户仍应检查自己的免费带宽与实例用量；这里不承诺免费、无限量或持续可用。
