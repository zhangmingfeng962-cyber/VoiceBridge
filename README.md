# VoiceBridge 0.10.0 · 音乐与屏幕房间

网站入口：[voicebridge-room.cn](https://voicebridge-room.cn/)。Windows 客户端已内置此地址，下载即可创建房间，无需导入配置或自建服务器。网站备案号：渝ICP备2026026961号-1。

## 新增屏幕共享

任何成员可选择软件窗口或显示器；一人共享，其余成员观看。支持更换来源、暂停／恢复、结束、放大、全屏、适应方式、流畅／均衡／清晰档和自动画质。画面暂停时不发送实时视频轨道，观看端显示占位画面。

共享声音复用已有程序音乐通道，独立于视频和麦克风；开关与音量在两处同步，同一声音只传一次。暂停或结束画面不会改变音乐开关。网页捕获画面时不申请整机声音，避免把房间声音回传。详细能力、限制、临时 TURN 凭据与部署步骤见 [屏幕共享说明](docs/SCREEN-SHARING.md)。

安装 Node.js 22+ 后，可在本机运行预览：

```powershell
cd relay
npm ci --ignore-scripts
cd ..
node scripts/Preview-Room.mjs
```

在 Edge / Chrome 打开控制台输出的本机邀请，再点击“进入房间”。可用另一个标签页观看。这个服务只监听本机，不需要改防火墙，也不能作为发给跨网朋友的公开地址。

Windows 客户端 + 浏览器音乐房间，最多 8 人。每个人可以讲话、共享自己选择的程序音频。音乐与人声分别编码、分别调音量，讲话不自动压低音乐。

0.9 只保留音乐房间，移除了虚拟麦克风、驱动安装、原语音软件场景、混响、托盘、自启动设置和临时穿透功能。关闭客户端即退出房间；主持人退出后整个房间关闭。

## 下载与使用

从[网站](https://voicebridge-room.cn/)或 [Releases](https://github.com/zhangmingfeng962-cyber/VoiceBridge/releases) 下载 `VoiceBridge-v0.10.0.exe`。Windows x64 单文件，无需安装 .NET 或虚拟声卡。

1. 下载后直接打开 EXE，输入昵称，点击 **创建房间**。软件已内置国内服务地址，无需导入配置，不附带私人建房密钥。
2. 客户端自动打开房间专属控制页。入房会自动开启真实麦克风，你可随时关麦或切换按键说话。首次用网页模式需要允许浏览器麦克风权限；拒绝权限时仍可收听，页面会显示原因。音乐共享仍需主动开启。
3. 在网页内调节麦克风增益（0–400%）、房间总收听音量（0–200%），选择自由发言或按键说话，并设置说话键。
4. 点击 **邀请朋友**。朋友打开邀请即可通过新版 Edge / Chrome 加入，不需要账号或主持人的建房配置。
5. 朋友如果也想共享微信、QQ 音乐或其他桌面程序，运行同一客户端，粘贴邀请并 **加入朋友房间**。不需要主持人的建房凭据。
6. 网页音源列表自动识别本机 WASAPI 音频会话，每两秒刷新。先让目标程序播放一次，选择它，再开始共享。可以在网页切换来源。每位成员可以同时共享自己的一路音乐。
7. 在网页昵称框中输入新昵称，点击 **保存昵称** 或按回车，全体成员立即看到更新。成员加入/退出有本地提示音，音量跟随房间总收听音量；修改昵称不会触发进出音效。
8. 成员列表可单独调节每个人的人声（0–200%）及音乐（0–100%），或者静音此人人声。这些设置只影响你自己。

网页音频共享通过浏览器选择器共享 **其他标签页的音频**，需要勾选共享标签页音频。网页不能直接枚举桌面音源；自动识别桌面音源依赖 Windows 客户端。仅开启标签页音乐时保留的本地视频轨道不上传；另行开启屏幕共享后，选中的画面通过独立 WebRTC 视频通道传输。

## 音质、延迟与使用边界

- 音乐为 48 kHz 双声道 Opus，目标 256 kbps；人声为 48 kHz 单声道 48 kbps；每帧 20 ms。高质量有损编码，并非与原音频逐位一致。视频目标默认 720p/30fps，根据网络降档；500ms 是待跨网实测的延迟目标。
- 每路接收缓冲初始 100 ms，依据到达抖动在 60–400 ms 间自动调整，积压超过约 800 ms 会丢弃旧音频。总延迟还包括设备、编码和网络，不能保证低于 100 ms，断网也无法通过缓冲消除。
- 本机程序共享使用 Windows Process Loopback，仅捕获所选程序及安全筛选后的同程序进程树。受保护音频、独占输出、部分特殊播放器可能无法捕获。
- **桌面程序音源共享需要 Windows 11 / Windows build 20348+**。Windows 10 2004+ 可运行客户端收听/讲话，或在 Edge/Chrome 网页模式共享标签页音频；不使用系统立体声混音。
- Windows 客户端把房间声音独立播放，专属控制网页不再重复收听，避免共享浏览器时把本房间声音传回。请关闭其他重复收听的房间标签页。共享整个浏览器或微信时会包含该程序的其他音频，不能把同一程序内部的不同通话拆开。
- 建议戴耳机。客户端麦克风不做自动增益或自动压低音乐；外放仍可能产生声学回声。网页麦克风请求回声消除/降噪并关闭自动增益，实际取决于浏览器与设备。
- 客户端按键说话使用配置按键的 Windows 键状态，无注入、无游戏进程挂钩。网页按键说话需要页面焦点，切走页面停止发送。不保证所有反作弊软件的兼容性。
- 过高增益或多人同时大音量会削波。麦克风偏小时可逐步增加增益，出现失真时调低。房间音量不会改变游戏或其他软件的系统音量。

## 配置与隐私

公开版已内置部署在杭州阿里云 ECS 的公共地址，任何人下载后都可创建房间，无需账号、密钥或配置文件。原“导入建房配置”按钮和 DPAPI 配置读取已移除。EXE 只含公共地址，不含管理员、证书私钥或 TURN 共享密钥。服务最多同时 4 个房间、每房间 8 人；匿名建房受限流保护，未连接主持人的匿名房间 30 秒过期。当前小型公共实例不保证无限并发；流量由站点维护者承担。自部署说明见 [中继部署](docs/DEPLOYMENT.md)。

入房邀请含房间解密密钥，请只发给希望加入的人。专属控制页还含控制本机设备的独立权限，**不要分享地址栏里的专属控制链接**，使用页面或客户端的“邀请朋友”按钮。

音频及本机设备/音源列表使用客户端 AES-GCM 加密。中继能看到成员昵称、当前共享来源名称、流量及连接信息；只转发音频，不录音、不保存音频文件。加密不能阻止已入房的人录音或转发邀请。服务器管理员仍控制所提供的网页代码，应使用可信的中继。

关闭控制页会立即关闭本机麦克风，客户端的音乐共享/收听可继续。点击“退出房间”或关闭客户端会停止本机所有采集及收听。主持人退出会关闭整个房间。每房间最长 2 小时，重新建房可继续。

## 构建与测试

Windows x64、.NET SDK 8.0.426（或兼容 8.0 SDK）、Node.js 22+。首次还原依赖需要联网。

```powershell
dotnet restore VoiceBridge.sln --locked-mode
dotnet test VoiceBridge.sln -c Release
dotnet publish src/VoiceBridge.App/VoiceBridge.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/win-x64
cd relay
npm ci --ignore-scripts
npm test
```

依赖：NAudio.Wasapi 2.2.1、Concentus 2.2.2、ws 8.22.0；测试 xUnit。锁文件随源码提交。第三方许可证见 `third-party/`。

自动测试验证禁用按钮深色样式、提示音边界、免配置建房限流、昵称更新、首次控制页保持入房开麦，以及独立增益、立体声编码、加密、控制权限隔离、音源进程树保护、缓冲上限和关麦/按键失效。测试结果不能替代朋友在不同网络上的实际试听。没有承诺永久免费的公共中继，试用额度耗尽会停止服务或需要平台账户持有人处理。
