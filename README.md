# VoiceBridge 0.12.0 · 游戏连麦与音乐房间

网站：https://voicebridge-room.cn/。Windows 安装版包含国内服务器地址，无需导入配置或自建服务器。0.11 用户需要安装一次新版，此后可在软件内检查更新。

## 使用

1. 下载安装版，按提示为当前 Windows 用户安装。无需额外安装 .NET 或虚拟声卡。
2. 填写昵称，创建房间并填写房间名。只有勾选“公开到房间大厅”才会对大厅访客开放；私密房间使用完整邀请加入。
3. 入房后自动开麦。底部可关麦、切换自由发言/全局按键说话，调整麦克风与房间收听音量；成员卡片分别调节每人的人声与音乐。
4. 播放目标程序，在“我的音乐”选择音源后共享。人声降噪不处理音乐，讲话不会自动压低音乐。
5. 点击关闭窗口会收起到托盘并继续连麦。使用“退出房间”离开，或托盘“退出程序”结束运行。屏幕共享通过独立画面页控制，关闭画面页不关闭原生麦克风。
6. 公开大厅可搜索、刷新和直接加入，房主管理入口支持改名、停止公开和移出成员。房主离开会转交管理权，活跃房间不限时，全员离开 30 分钟后回收。最多 4 房间、每房间 8 人。

## 更新与下载

安装版启动时、每 6 小时检查签名更新清单。点击更新可查看设置栏中的版本说明。在房间内只预约退房后更新，不下载、安装或重启连麦进程。离开房间后才准备更新；签名、包大小或 SHA256 校验失败时保留当前版本。可用差分包时优先差分，否则回退完整包。下载使用服务器全局共享预算，空闲最高 1 MiB/s，有语音/视频负载时减速。实际速度受现有 10 Mbps 公网带宽限制。

安装文件位于 `%LOCALAPPDATA%\VoiceBridge.Desktop`，与旧版资料目录分开。昵称与音频偏好保存在 `%APPDATA%\VoiceBridge\preferences.json`，卸载、移动旧 EXE 或更新不要求重新填写；网页昵称保存在本站本地存储。旧客户端仍可使用私密邀请，但不提供原生大厅及软件内更新。

## 构建

- Windows 10/11 x64；程序独立音频捕获需要 Windows build 20348+。较早 Win10 可连麦和收听，程序捕获受系统接口限制。网页可选择其他标签页声音，不能枚举所有桌面程序。
- 固定 SDK .NET 10.0.403，随包运行时 10.0.14；Node.js 22.23.3；Velopack CLI/NuGet 1.2.161。音频 NAudio 2.2.1、Concentus 2.2.2、RNNoise 0.2。
- `dotnet restore VoiceBridge.sln --locked-mode`，`dotnet test VoiceBridge.sln -c Release`。
- `cd relay` 后 `npm ci --ignore-scripts`、`npm test`。
- `pwsh scripts/Build-Installer.ps1` 构建安装版与更新包；`scripts/Package-Preview.ps1` 打包源码。
- RNNoise 原生 DLL 已随源码提供，重建及许可见 `third-party` 与 `scripts/Build-RNNoise.sh`。

## 服务器与隐私

服务沿用杭州 ECS、域名、HTTPS 与 TURN，运行说明见 `docs/DEPLOYMENT-0.12.0.md`。默认服务不是无限容量；房间是内存会话，维护重启后需要重新建房。公开列表不返回私密邀请、客户端控制或恢复凭据。公开房间入房材料由服务器发放，不能沿用私密邀请的隐私承诺。音频为有损 Opus 48 kHz；屏幕 1080p60 是设备与网络允许时的目标。

更新验证公钥可随源码公开。签名私钥仅放在受限发布环境，绝不能上传 GitHub、放进客户端或服务公开目录。没有 Windows 商业代码签名证书，更新清单签名不等于 Windows Authenticode 签名。

验证证据及尚未覆盖的真实设备、DPI、跨网听感边界见 `docs/VERIFICATION-0.12.0.md`。
