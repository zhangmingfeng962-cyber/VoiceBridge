# VoiceBridge 0.11.0 · 音乐房间

网站：[voicebridge-room.cn](https://voicebridge-room.cn/)。Windows 客户端已内置杭州公共服务，下载即可创建房间；朋友通过完整邀请加入，无需导入配置或自建服务器。网站备案号：渝ICP备2026026961号-1。

## 一起听，自在聊

- 房间内任何成员都可共享一路本机程序音乐，同时讲话。麦克风与音乐分别编码、加密、调节音量，不因讲话自动压低音乐。
- 麦克风增益 0–400%，总收听音量 0–200%，每位成员的人声与音乐独立调节。
- 自由发言、按键说话、修改昵称、成员进出提示音。客户端运行时可在游戏后台使用说话键；网页模式需要页面焦点。
- 活跃房间不设使用时限，房主离开不散房。全员离开 30 分钟后释放房间；创建后从未入房的请求仍短期回收。服务器维护重启后需重新建房。
- 网络中断后保留成员身份 90 秒并自动恢复。重连中保留音量选择，停止过期音频积压，不重复播放进出提示音；主动退出取消重试。
- Windows 昵称及降噪选择保存在当前用户的 AppData，移动 EXE 不丢失。网页独立使用时保存在本站本地存储；没有跨设备账户同步。

## 麦克风降噪

新增独立开关，默认开启。Windows 使用随软件打包的 RNNoise 0.2，在增益与编码前处理麦克风；网页使用浏览器原生降噪，实际支持情况由设备和浏览器决定。旧版客户端需要更新后才支持新降噪开关。

音乐通道不经过降噪，不增加自动增益、语音门限或自动压低音乐。降噪不保证消除所有环境噪声；如果轻声说话受影响，可关闭降噪。过高增益及多人高音量叠加仍可能造成失真。

## 屏幕共享

任意成员可选择窗口或显示器，同一时间一人共享，其余成员观看。支持暂停／恢复、更换来源、停止观看、小窗、放大、全屏及适应窗口。

默认清晰优先，目标为 1080p、最高 60 帧；均衡为 1080p30，流畅为 720p30。尽量保持分辨率，拥塞时先降低帧率，界面显示实际发送或接收参数。目标档位不等于实际画质保证，设备、捕获源刷新率、网络和观看人数均会影响结果。

共享声音复用已有音乐通道，只发送一次。结束画面不会自动停止音乐；停止声音请关闭音乐／共享声音开关。每次选择新画面都由你主动确认，入房不会自动共享屏幕。

视频优先直连，必要时使用本服务器 TURN 中继。临时凭据续期通过现有连接上的 ICE restart 完成，直连和中继采用不同预算；双端中继计入双段流量，保留传输开销余量。现有 10 Mbps 公网峰值和中继流量限制不能保证多人都达到 1080p60。

## 使用

1. 从网站或 [GitHub Releases](https://github.com/zhangmingfeng962-cyber/VoiceBridge/releases) 下载最新版单文件 EXE。
2. 首次填写昵称，点击“创建房间”；下次自动恢复昵称。客户端会打开本机专属网页控制页。
3. 入房自动开启真实麦克风，可随时关麦或切换按键说话。网页首次使用需要允许麦克风权限；拒绝后仍可收听。
4. 点击“邀请朋友”复制普通邀请。专属控制页具有本机控制权限，不要把它当作朋友邀请转发。
5. 让要共享的程序先播放一次，再在网页选择音源并开始共享。每位成员都可以共享自己的音乐；本机播放器音量不受房间音乐音量影响。
6. 如需画面，展开屏幕共享小卡片并主动选择窗口或显示器。语音、音乐和成员音量继续独立控制。

退出网页独立房间或关闭客户端会停止对应采集与收听。关闭专属控制网页会关闭客户端麦克风；音乐共享与收听可继续，完整退出请使用客户端“退出房间”。建议戴耳机，避免扬声器声音重新进入真实麦克风。

## 兼容性与边界

Windows 10/11 x64，可进行语音与收听。任意桌面程序音源独立捕获需要 Windows 11 / build 20348+；较早 Windows 10 可用新版 Edge/Chrome 共享其他浏览器标签页的音频。网页自身不能枚举所有桌面程序，程序列表由客户端每两秒检测一次。

客户端独立播放房间声音，避免将控制网页的房间声音混回被共享的浏览器。共享整个浏览器或微信时会包含该程序的其他音频，不能拆分同一程序内部的不同通话。请关闭重复收听的房间页。

音乐使用 48 kHz 立体声 Opus、目标 256 kbps、20 ms 帧，是高质量有损传送，不是原始 PCM 逐位复制。麦克风为 48 kHz 单声道。网络、设备、多路混音和缓冲仍会影响实际听感与延迟。

公开服务最多同时 4 个房间、每房间 8 人，建房有限流；流量由站点维护者承担。不承诺无限并发或永久免费的云资源。0.9 已按产品范围移除虚拟麦克风、驱动、原语音软件场景、混响、托盘、自启动和临时穿透，本版继续保留房间产品范围。

## 依赖和编译

- .NET SDK 8.0.426，Windows x64。
- Node.js 22+，用于中继与跨语言集成测试。
- NAudio.Wasapi 2.2.1、Concentus 2.2.2、ws 8.22.0，锁文件随附。
- RNNoise 0.2 Windows x64 DLL 随源码提供，编译 .NET 时无需额外 C 编译器。来源、校验与重新构建步骤见 [0.11.0 说明](docs/CHANGES-0.11.0.md)；许可见 third-party/RNNoise-COPYING.txt。

在 Windows 的项目根目录执行：

~~~powershell
dotnet restore VoiceBridge.sln --locked-mode
Push-Location relay
npm ci --ignore-scripts
npm test
Pop-Location
dotnet test VoiceBridge.sln -c Release --no-restore
dotnet publish src/VoiceBridge.App/VoiceBridge.App.csproj -c Release -r win-x64 --self-contained true --no-restore -o artifacts/win-x64
powershell -File scripts/Package-Preview.ps1 -ExecutablePath artifacts/win-x64/VoiceBridge.exe -OutputDirectory artifacts/release
~~~

发布后的 EXE 包含 .NET 与原生降噪组件；使用者无需安装 .NET、虚拟声卡或降噪驱动。自行部署中继可参考 docs/DEPLOYMENT.md；云端管理密钥与 TURN 共享密钥只能留在服务器，不能编译到公开客户端。

## 隐私与验证

音频与本机设备／音源控制状态使用 AES-GCM 加密。服务器可以看到成员昵称、当前共享来源名称及连接信息，不录音、不保存音频文件。已入房的人仍可自行录音或转发邀请；请仅分享有权分享的内容。

恢复凭据独立于朋友邀请，仅在会话中保存；昵称设置仅保存在自己的设备。Windows 客户端与网页不加入实名资料收集功能。ICP备案通过不代表其他安全评估已通过。

测试说明见 [0.11.0 验证记录](docs/VERIFICATION-0.11.0.md)。合成音视频验证不能替代两台独立电脑和朋友端的实际音质、画质及延迟验收。
