好音乐，
和朋友一起听。

在同一个房间听歌、讲话、分享画面。人声与音乐独立传送，每个人都能调出舒服的音量。

下载 Windows 客户端我有房间邀请

Windows 11 x64 · 支持应用音频捕获的 Windows 版本 · 下载后直接创建房间，无需配置服务器

一起听

每位成员都可选择本机程序音源共享。音乐采用 48 kHz 立体声 Opus 编码。

自在聊

自由发言或按键说话，分别调节麦克风、总收听和每位朋友的音量。

分享画面

选择窗口或显示器，同一时间一人共享。支持暂停、切换来源和全屏观看。

朋友可以用浏览器加入；分享桌面程序的声音时，请运行客户端。进入房间会请求麦克风权限。

三步，和朋友碰面

  1. 下载并打开客户端，输入昵称，点击“创建房间”。
  2. 点击“邀请朋友”，把完整邀请发给朋友。
  3. 在房间网页里选择音源、调整音量，或开始共享画面。

房间最多 8 人，当前公共服务最多同时 4 个房间。房主退出后房间关闭，单次房间最长 2 小时。请妥善保管邀请：任何获得完整邀请的人都可以加入。人声与音乐在设备上加密后传送；网络、设备及多人混音可能影响延迟和听感。

请仅分享你有权分享的内容。需要反馈问题，可前往 GitHub 问题反馈，请勿公开房间邀请和个人资料。
